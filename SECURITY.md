# Security

Do not include tokens, authorization headers, account claims, passwords, certificates or client secrets in reports. Provide package/native SDK versions, integration path, sanitized error codes and reproduction steps.

WikiLift has not supplied a private security contact for this package. For a sensitive vulnerability, obtain a private reporting route from the maintainer before disclosing details publicly. Use Microsoft's own security reporting process for vulnerabilities in MSAL.

Apple MSAL is pinned to 2.0.0 for iOS 15 compatibility. This pin is not a guarantee of upstream maintenance or security support. Review upstream fixes and platform requirements before upgrading or releasing.
